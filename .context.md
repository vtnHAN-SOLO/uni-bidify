# PTUDW - Online Auction System - Project Requirements

## Project Overview

Build an Online Auction Platform with the following subsystems and features:

---

## 1. Guest User Subsystem (Anonymous Users)

### 1.1 Menu System

- Display category list (2-level hierarchy):
    - Electronics → Mobile Phones
    - Electronics → Laptops
    - Fashion → Shoes
    - Fashion → Watches

### 1.2 Home Page

- Top 5 products ending soon
- Top 5 products with most bids
- Top 5 products with highest price

### 1.3 Product List View

- View by category
- Pagination support

### 1.4 Product Search

- Full-text search functionality
- Search by product name and/or category
- Paginated results
- Sorting options:
    - End time (descending)
    - Price (ascending)
- Highlight new products (posted within N minutes)

#### 1.4.1 Product List Display Information

- Product thumbnail image
- Product name
- Current price
- Current highest bidder info
- Buy Now price (if available)
- Posted date
- Time remaining
- Current bid count
- Clickable category to navigate to product list

### 1.5 Product Detail View

**Full product information:**

- Main image (large size)
- At least 3 additional images
- Product name
- Current price
- Buy Now price (if available)
- Seller info & rating
- Current highest bidder info & rating
- Posted timestamp
- End timestamp (relative format if < 3 days: "3 days left", "10 minutes left")
- Detailed description
- Q&A history between participants and seller
- 5 other products in same category

### 1.6 Registration

**Requirements:**

- reCaptcha verification
- Password encryption using bcrypt or scrypt
- Required information:
    - Full name
    - Address
    - Email (unique, with OTP verification)

## 2. Bidder Subsystem (Buyers)

### 2.1 Watch List

- Add product to Watch List from:
    - Product List view
    - Product Detail view

### 2.2 Place Bid

**Requirements:**

- Rating validation: Only users with 80%+ positive rating can bid
    - Example: 10 ratings (8 positive, 2 negative) = 80% = allowed
    - Users with no rating can bid if seller allows
- System suggests valid bid (current price + step price)
- Confirmation required

### 2.3 View Bidding History

**Masked bidder information:** | Time | Bidder | Price |
|------|--------|-------| | 27/10/2025 10:43 | \***\*Khoa | 6,000,000 | |
27/10/2025 9:43 | \*\***Kha | 5,900,000 |

### 2.4 Ask Seller Questions

- From Product Detail view
- Seller receives email notification with direct link to product

### 2.5 Profile Management

- Update email, name, password (requires old password)
- View rating score and detailed feedback
- View Watch List
- View participating auctions
- View won auctions
- Rate seller (+1/-1) with comment

### 2.6 Request Seller Upgrade

- Bidder can request upgrade to seller
- Admin approval required (7-day review period)

## 3. Seller Subsystem

### 3.1 Post Auction Product

**Required information:**

- Product name
- Minimum 3 images
- Starting price
- Step price
- Buy Now price (optional)
- Description (WYSIWYG editor: Quill.js or TinyMCE)
- Auto-extend option:
    - If enabled: extend 10 minutes when bid placed within last 5 minutes
    - Parameters (5 min, 10 min) configurable by admin

### 3.2 Update Product Description

- Append new information to existing description
- Cannot replace old description
- Example format with timestamps: [Original description]

✏️ 31/10/2025

[New information 1]

✏️ 5/11/2025

[New information 2]

### 3.3 Reject Bidder

- From Product Detail view
- Rejected bidder cannot bid on this product again
- If rejected bidder has highest bid, product goes to second-highest bidder

### 3.4 Answer Questions

- From Product Detail view

### 3.5 Profile Management

- View active product listings
- View products with winning bidder
- Rate winner (+1/-1) with comment
- Cancel transaction (auto -1 rating with "Buyer did not pay" comment)

## 6. System Features

### 6.1 Mailing System

**Email notifications for:**

1. **Successful bid, price updated:**
    - To: Seller, New bidder, Previous highest bidder (if any)

2. **Bidder rejected:**
    - To: Bidder

3. **Auction ended, no buyer:**
    - To: Seller

4. **Auction ended:**
    - To: Seller, Winner

5. **Buyer asked question:**
    - To: Seller

6. **Seller answered question:**
    - To: All auction participants, All questioners

### 6.2 Automatic Bidding

**System supports proxy bidding:**

- Buyer sets maximum price willing to pay
- Current price auto-updates based on maximum prices
- If two bidders set same max price, earlier bidder wins

**Example - Regular Bidding:** | Bidder | Bid Price | Product Price | Price
Holder | |--------|-----------|---------------|--------------| | #1 | 10,000,000
| 10,000,000 | #1 | | #2 | 10,100,000 | 10,100,000 | #2 | | #3 | 10,500,000 |
10,500,000 | #3 |

**Example - Automatic Bidding:** | Bidder | Max Price | Product Price | Price
Holder | |--------|-----------|---------------|--------------| | #1 | 11,000,000
| 10,000,000 | #1 | | #2 | 10,800,000 | 10,800,000 | #1 | | #3 | 11,500,000 |
11,100,000 | #3 | | #4 | 11,500,000 | 11,500,000 | #3 |

**Note:** Implement either automatic OR regular bidding, not both.

## 7. Post-Auction Checkout Process

**After auction ends:**

- Winner and seller see "Complete Order" view
- Other users see basic info with "Auction Ended" message

**4-step completion process:**

1. Buyer provides payment proof and shipping address
2. Seller confirms payment and provides shipping invoice
3. Buyer confirms receipt
4. Both parties rate transaction (+/- with short comment)

**Additional features:**

- Seller can cancel transaction anytime (-1 rating to winner)
- Chat interface between seller and winner
- Both parties can update ratings anytime

## Key Business Rules Summary

1. **Rating System:** 80%+ positive rating required to bid (unless no rating and
   seller allows)
2. **Auto-extend:** Configurable by admin, applies to all products
3. **Bidder Rejection:** Rejected bidder cannot bid on that product again
4. **Price Steps:** Defined by seller per product
5. **Proxy Bidding:** System automatically bids up to user's maximum price
6. **Email Notifications:** Sent for all major transactions
7. **Post-Auction:** 4-step checkout process with chat support
8. **Ratings:** Can be updated by both parties after transaction
